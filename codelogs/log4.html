CSS Color

What do these CSS properties do?

  • color controls the color of text inside an element
  • background-color sets the background color of an element’s box. This color fills the entire area behind the content, padding, and behind the border.
  • border-color defines the color of an element's border

How does CSS accept color as a value?

  • Named: CSS supports predefined color names.
  • Hexadecimal: Colors can be specified using hex codes representing RGB values, starting with # followed by 3 or 6 hexadecimal digits.
  • RGB: Colors can be defined using the rgb() function with red, green, and blue values from 0 to 255.
  • - RGBA: Like RGB but with an alpha channel for transparency (0 to 1).
