CSS Color

What do these CSS properties do?

  • color controls the color of text inside an element
  • background-color: sets the background color of an element. It fills the entire area of the element’s content + padding + border (but not the margin) with a solid color. If the element also has a background-image, the color will appear behind the image and can show through if the image has transparency.
  • border-color: sets the color of an element’s border. It works together with the border-style and border-width properties — if no border style is set (solid, dashed), the color won’t be visible.

How does CSS accept color as a value?

  • Named: CSS defines over 160 standard color names (e.g., red, blue, green, lightseagreen, rebeccapurple) that map to specific RGB values.
  • Hexadecimal: Colors can be specified in #RRGGBB format (3 or 6 digits) for RGB components, or with an #RRGGBBAA format for RGBA (including alpha/transparency).
  • RGB: rgb(r, g, b) where r, g, b are integers from 0–255.
  • RGBA: Like RGB but adds an alpha channel for opacity (0 = transparent, 255 = opaque).
